# Site — Dra. Marcella Maia

## Estrutura
```
index.html        → site completo (HTML/CSS/JS em um único arquivo)
assets/           → logo, fotos e glifo decorativo
robots.txt        → indexação para buscadores
sitemap.xml       → mapa do site para SEO
```

## Como publicar
Basta subir a pasta inteira para qualquer hospedagem (Hostinger, Vercel, Netlify, cPanel etc.) e apontar o domínio para `index.html`. Não há dependências de build — é HTML puro, funciona em qualquer servidor estático.

## O que ainda pode ser adicionado
- **Resultados**: a seção "Resultados" está com espaços reservados elegantes. Basta substituir os blocos `.result-slot` em `index.html` por fotos reais (antes/depois) quando estiverem disponíveis.
- **Instagram**: a grade já usa fotos reais e cada quadro é um link direto para `instagram.com/dramarcellamaiaa`. Quando quiser, pode trocar as imagens dos tiles por prints reais do feed mais recente.
- **Domínio real**: troque `https://dramarcellamaia.com.br/` em `index.html`, `robots.txt` e `sitemap.xml` pelo domínio definitivo.
